# «Колибри» — Telegram + AlfaCRM

Telegram-версия использует полный набор бизнес-сценариев Kolibri MAX, но
источником данных остаётся **AlfaCRM**.

## Возможности

- обязательный вход по телефону, поиск преподавателя/родителя в AlfaCRM;
- воронка нового клиента: возраст каждого ребёнка → подходящее направление →
  заявка и уведомление менеджеру;
- расписание за стандартный или произвольный период, ДЗ и остаток занятий;
- посещаемость, неявки, индивидуальное/групповое ДЗ и отчёты преподавателя;
- заморозки с дедлайном, справками и лимитом беспричинных заморозок;
- заявки на перенос, поддержка с ответом менеджера;
- рассылки, сводки, обработка неявок, список лидов и журнал активности;
- персональные напоминания и фоновые задачи.

Обработчики разделены с транспортом: `telegram_adapter.py` переводит обновления
aiogram в общий интерфейс сценариев. Благодаря этому Telegram и MAX используют
одинаковую логику, а CRM-слой здесь — `alfacrm_client.py`.

## Запуск

```powershell
pip install -r requirements.txt
# создать .env и заполнить как минимум:
# BOT_TOKEN=...
# ALFACRM_URL=...
# ALFACRM_EMAIL=...
# ALFACRM_API_KEY=...
# BRANCH_ID=1
# ADMIN_TELEGRAM_IDS=123456789
python main.py
```

Дополнительно настраиваются `MANAGER_PASSWORD`, `SCHOOL_NAME`,
`SCHOOL_SITE`, параметры заморозок и расписания в `settings.py`.

При первом запуске существующая база старой Telegram-версии обновляется на
месте: Telegram-привязки, заявки и журнал напоминаний сохраняются. Перед
обновлением production-инсталляции всё равно рекомендуется сделать копию
`bot.db`.

## Структура

- `bot/handlers/` — сценарии родителя, преподавателя, менеджера, лидов и поддержки;
- `max_api/` — нейтральные контексты/клавиатуры общего слоя (название сохранено
  для совместимости);
- `telegram_adapter.py` — отправка сообщений, файлов и клавиатур через Telegram;
- `alfacrm_client.py` — AlfaCRM v2 API;
- `database.py` — локальные связи, ДЗ, заявки, заморозки и журнал активности;
- `scheduler.py` — напоминания и ежедневные задачи.
